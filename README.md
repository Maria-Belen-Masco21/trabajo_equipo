# Proyecto Flask con Blueprints

## Tecnologías
- Flask
- Flask SQLAlchemy
- Flask Migrate
- Bootstrap 5
- SQLite

## Instalación
```bash
pip install -r requirements.txt
```

## Ejecutar migraciones
```bash
flask db init
flask db migrate -m "Inicial"
flask db upgrade
```

## Ejecutar aplicación
```bash
python run.py
```
